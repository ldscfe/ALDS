# {Project} Project Pulse

## Positioning & Scope

This document is the project-level implementation planning and progress overview, generated by `.AI/project/init.md`. As a high-level implementation pulse, it focuses on overall project rhythm, phase planning, and task ledger, not expanding technical details, spec constraints, or execution-level work orders.

**Key Contents:**

- Overall implementation rhythm & phase planning
- Major milestones & current status
- Project-level Functional Task Brief Ledger (high-level, non-execution)
- Non-core task coarse-grained ledger (optimization, defects, governance, technical debt, etc.)
- Major risks & pending confirmations
- Implementation priorities & high-level dependencies
- High-level verification methods or evidence sources

**Must Not Contain:**

- Technical details, spec descriptions, architecture constraints, or code implementation plans
- Execution-level work order content or status
- Work-order-level verification steps, command outputs, execution logs, or acceptance details
- Current scope, governance status, freeze rules, or other regulatory content
- Any work order as independent main entry or primary record object

Subsequent standard tasks should select entries from this document's **Project-Level Task Brief Ledger**, then generate formal task briefs and work orders per `.AI/start.md`.

## Prohibited Structure

- Must not use work orders as project pulse independent main entries or primary record objects
