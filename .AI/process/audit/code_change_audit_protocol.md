# Code Change Audit Protocol

This protocol defines the minimum audit loop for implementation work.

## Required Stages

1. Assessment
2. Task Brief
3. Work Order
4. Implementation
5. Verification
6. Audit
7. Archive

## Required Records

- Task Objective
- Affected Scope
- Verification Evidence
- Approval Status
- Final Archive Location

## Closure Rule

Must not mark complete before recording verification results and approval results.
