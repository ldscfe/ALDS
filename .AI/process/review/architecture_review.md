# Architecture Review Checklist

Used when task changes architecture, system boundaries, invariants, workflows, or governance text.

## Review Focus

1. Is change rationale clear and evidenced
2. Are affected boundaries clearly named
3. Are downstream documents and processes identified
4. Is verification path clearly defined

## Result Types

- `approved`
- `needs_update`
- `rejected`
